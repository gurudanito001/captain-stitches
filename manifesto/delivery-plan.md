# Delivery Plan — 6 Weeks

## Phase 1 — Weeks 1–2: Foundation
- Homepage, About, Contact pages.
- Catalogue creation and SEO metadata implementation.
- Order form and measurement collection.
- Payment gateway integration (Paystack + Stripe).
- Email capture integration.
- Basic admin orders kanban board.

## Phase 2 — Weeks 3–4: Operations
- Order tracking page.
- Tailor account access (status updates and media uploads).
- Video inspection workflow implementation.
- Customer profiles and measurement storage.
- Customer reviews on design pages.
- Admin alerts for overdue orders and pending inspections.

## Phase 3 — Weeks 5–6: Growth
- Referral programme deployment.
- Blog and admin editor integration.
- English/Italian language toggle implementation.
- Currency toggle (₦ / €) implementation.
- Dormant subscription provision architecture.
- Analytics, settings configuration, and access control.
